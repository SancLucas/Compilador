¿Qué es un lenguaje de programación?
	Conjunto de símbolos, palabras y reglas que permiten escribir programas.
		>> sintaxis, semánntica, token, gramática, léxico, etc.

=============================================================
PL/0 >> análisis léxico >> a. sintáctico >> a. semántico >> generación de código >> ejecutable
=============================================================

* Léxico.
	Se compone del conjunto de palabras, simbolos y signos que forman las unidades básicas de un lenguaje
de programación. El compilador lee los coracteres y los agrupa/reconoce como unidades léxicas o tokens.

	Ejemplo:
		contador := 10;	| "contador" | identificador
				|     " := "	    | asignación
				|        10	    | número
				|       ' ; '	    | punto y coma
===========================================

* Sintaxis.
	Describe cómo deben estar organizados los elementos de un programa para que formen
una construcción válida del lenguaje.

	Ejemplo:
 		identificador := expresión;
==============================

* Semántica.
	Se ocupa del significado del programa: qué representa cada construcción y si su uso
tiene sentido dentro del lenguje.

	Ejemplo: asignar un dato a un identificador que no fue declarado.
===============================================

Palabras reservadas.
	Son palabras que tienen un significado especial para el lenguaje. No funcionan como
nombres libres de variables o procedimientos.

	Ejemplos: BEGIN, END, VAR, CONSTANTE, PROCEDURE, CALL, IF,
		THEN, WHILE, DO, ODD, READLN, WRITE, WRITELN, ...
=================================================

Identificadores:
========= son nombre definidos por el programador, por ejemplo, el nombre de una variable o procedimiento.

Constantes:
======= representa un valor que se declara con un nombre. Ejemplo: CONSTANTE limite = 10;

Variables:
======	indica una posición o espacio en donde puede almacenarse un valor, con la posibilidad de modificarlo
durante la ejecución. Ejemplo: VAR contador, suma;


Asignación:
======= permite guardar el resultado de una expresión en una variable. Ejemplo: contador := contador+1;

Expresiones y operadores:
================ combina valores, identificadores y operadores para producir un resultado.
>> suma [+]	>> resta [-]	>> multiplicación [*]	>> división [/]	>> paréntesis [( )]

	[No todos los operadores tienen la misma prioridad]
expresión >> términos >> factores ================
				- 2 + 3 * 4
				- (2 + 3) * 4

Condicionales / "simbolos":
========= mayor [>] ; menor [<] ; igual [=] ; distinto [#] ; mayor o igual [>=] ; menor o igual [<=] ; ODD [impar]
